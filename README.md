# LuloLenceria

Tienda Online / E-commerce moderna para **Lulo Lencería** construida con Next.js, React, Tailwind CSS y Prisma.

- Bikinis de Diseño
- Lencería Fina
- Indumentaria Deportiva
- Línea Exclusiva +18 (Aviso de ingreso restringido por edad)
- Checkout directo vía WhatsApp (Sin pasarela de pagos)
- Panel del Propietario / Administración (`/admin`)
